Városvégi Gimnázium – Elektronikus Napló Alkalmazás

Főoldal JavaScript React SPA Fetch API Axios OOJS

Az alkalmazásról

Ez a webalkalmazás a Városvégi Gimnázium elektronikus naplójának adatait kezeli. Az adatbázis egy tanév első négy hónapjában bejegyzett jegyeit tartalmazza, három fő táblával: diákok, tárgyak és jegyek.

Az alkalmazás bemutatja a modern webes technológiák széles körét: natív JavaScript, React, Single Page Application, Fetch API, Axios és objektum-orientált JavaScript.
